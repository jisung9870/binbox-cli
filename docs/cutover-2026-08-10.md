## Shell cutover follow-up

The old `.zshrc` block sourced `/home/ubuntu/setup/binbox/shell/init.zsh`, even
though command execution already resolved to `/home/ubuntu/.local/bin/bb`.
After installing a binary that provides `bb shell init zsh`, the block is
replaced with `eval "$(bb shell init zsh)"`. A timestamped copy of `.zshrc` is
kept under `$XDG_STATE_HOME/bb/cutover-backups` for manual rollback. This keeps
`bb wenv <preset>` current-shell behavior without a legacy checkout dependency.
