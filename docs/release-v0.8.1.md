# v0.8.1

`v0.8.1` makes the integrated secret manager list denser and easier to scan.

- Secret identities render as one `service / field` row instead of a service
  row with an indented field metadata row.
- Selectors containing no descriptions use one row per result and no longer
  reserve blank detail lines.
- Stable service/field values, search terms, actions, confirmations, and secret
  non-disclosure behavior are unchanged.
